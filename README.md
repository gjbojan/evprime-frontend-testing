# EVPrime Frontend Testing

## Overview

EVPrime Frontend Testing is an automated UI testing framework built with Java, Selenium WebDriver, JUnit 5 and Maven. The project validates the functionality of the EVPrime web application through end-to-end automated test scenarios using the Page Object Model (POM) design pattern.

## Technologies

- Java
- Selenium WebDriver
- JUnit 5
- Maven
- Page Object Model (POM)
- Git

## Project Structure

- **base** – Base classes for setup, reusable functionality and common test prerequisites
- **pages** – Page Object classes containing page locators and UI interaction methods
- **components** – Reusable UI components shared across multiple pages
- **tests** – Automated UI test classes organized by application features and user scenarios

## Test Coverage

The framework covers:

- Authentication (Sign Up, Login and Logout)
- Navigation
- Contact Form
- Event CRUD operations
- Positive scenarios
- Negative scenarios
- Boundary value testing
- Parameterized tests

## Design Principles

- Page Object Model (POM)
- Reusable page methods
- Reusable UI components
- Separation of test logic from page interactions
- Clean and maintainable project structure
