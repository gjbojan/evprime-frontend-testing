EVENTS Acceptance Criteria
NOTE: - User must be logged in to create, edit, update, or delete events
	  - Event list and event details can be viewed without login

Test Scenario 1: Add Event Menu Navigation
Pre-requisite: User is logged in
GIVEN the user is on any page of the EVPrime application
WHEN the user hovers over the add an event (+) in the blue circle in the down right corner area
AND the add an event (+) button changes into an (x) button
AND the button background darkens
AND another "Create an event" button in a white circle on top of it has appeared 
WHEN the user hovers over the "Create an event" button
AND the button background darkens
AND the buttons name "Create an event" is shown
WHEN the user clicks on the "Create an event" button
THEN the user is redirected to the EVPrime "http://localhost:3000/events/new" Create new event page

Create New Event Page Acceptance Criteria

NOTE: - If user is not already on the Create New Event page, navigation can be performed via:
	  - Hovering on the add an event (+) option down right corner area then clicking on the "Create an event" button 
	  - Hover effects are covered in a dedicated scenario and are not repeated in the functional scenarios
      - Click effects are covered in a dedicated scenario and are not repeated in the functional scenarios

Pre-requisite: User is logged in

Test Scenario 2: Verify hover effects on UI elements
GIVEN the user is on the EVPrime "http://localhost:3000/events/new" Create New Event page
WHEN the user hovers over the Event Title field
THEN the field is highlighted
WHEN the user hovers over the Event Image field
THEN the field is highlighted
WHEN the user hovers over the Event Date field
THEN the field is highlighted
WHEN the user hovers over the Event Location field
THEN the field is highlighted
WHEN the user hovers over the Event Description field
THEN the field is highlighted
WHEN the user hovers over the "CREATE EVENT" button
THEN the button background color darkens

Test Scenario 3: Verify effect on clicking on the fields
GIVEN the user is on the EVPrime "http://localhost:3000/events/new" Create New Event page
WHEN the user clicks on the Event Title field
THEN the field label moves above the input field
AND the field label color changes to blue
AND the input field border changes to blue
WHEN the user clicks on the Event Image field
THEN the field label moves above the input field
AND the field label color changes to blue
AND the input field border changes to blue
WHEN the user clicks on the Event Date field
THEN the field label moves above the input field
AND the field label color changes to blue
AND the input field border changes to blue
WHEN the user clicks on the Event Location field
THEN the field label moves above the input field
AND the field label color changes to blue
AND the input field border changes to blue
WHEN the user clicks on the Event Description field
THEN the field label moves above the input field
AND the field label color changes to blue
AND the input field border changes to blue

Test Scenario 4: Functional "CREATE EVENT" button - Successful Create A New Event scenario
NOTE: - Valid value for the Event Image field means an URL with http/https
	  - Every new created event is next in line
GIVEN the user is on the EVPrime "http://localhost:3000/events/new" Create New Event page
WHEN the user enters any value in the Event Title field
AND the user enters valid value in the Event Image field
AND the user enters any value in the Event Date field
AND the user enters any value in the Event Location field
AND the user enters any value in the Event Description field
AND the user clicks on the "CREATE EVENT" button
THEN the user is redirected to the EVPrime "http://localhost:3000/events" Events page
AND the new event is added in the list

Test Scenario 5: Unsuccessful creation of a new event - All Fields Empty
NOTE: - Validation for empty fields is currently not fully implemented
	  - Submitting empty fields currently triggers an application error instead of displaying validation messages
GIVEN the user is on the EVPrime "http://localhost:3000/events/new" Create New Event page
WHEN the user leaves the Event Title field empty
AND the user leaves the Event Image field empty
AND the user leaves the Event Date field empty
AND the user leaves the Event Location field empty
AND the user leaves the Event Description field empty
AND the user clicks on the "CREATE EVENT" button
THEN an unexpected application error is displayed

Test Scenario 6: Unsuccessful creation of a new event - Invalid Event Image URL
NOTE: - Validation for invalid image URLs is currently not fully implemented
	  - Submitting an invalid image URL currently triggers an application error instead of displaying validation messages
	  - Image URLs must start with http or https
GIVEN the user is on the EVPrime "http://localhost:3000/events/new" Create New Event page
WHEN the user enters any value in all required fields
AND the user enters an image URL without http or https
AND the user clicks on the "CREATE EVENT" button
THEN an unexpected application error is displayed
