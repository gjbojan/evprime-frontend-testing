Sidebar - Test Cases

NOTE: - The sidebar is visible by default in collapsed mode
	- The expanded state additionally displays navigation labels
	- Navigation behavior is identical in both collapsed and expanded sidebar states
	- The sidebar is available on every page

Global Pre-requisite/Note: - For test cases that require an authenticated user, log in with valid credentials before executing the steps
				   - If this particular testing user is not created, create the user by:
				     - Clicking on the "Login" option at the sidebar
				     - Clicking on the "CREATE USER" button
				     - Enter an email (testuser@email.com)
				     - Enter a password (testuser123)
				     - Click on the "GO" button
				   - If the user already exists, use the credentials to log in

Test Case 1:
	Test Description: Verify functional usage of "Three lines" (Menu) button
	Test Steps: 1. Go to the EVPrime "http://localhost:3000/" Home page
			2. Hover over the "Three lines" (Menu) button
			3. Verify that a circular hover effect appears
			4. Click on the "Three lines" (Menu) button
	Expected Result: - A circular hover effect appears
			     - The sidebar expands
			     - Navigation labels are displayed next to the icons
	Actual Result: Same as Expected Result
	Status: PASS
